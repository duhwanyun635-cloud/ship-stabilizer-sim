# 선박 2축 안정화 시뮬레이터 v3 — 바뀐 점과 사용법

## 파일 (모두 같은 폴더에 두기)
| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 앱 (화면) |
| `verified_sim.py` | 계산 엔진. 출처가 확인된 식만 사용. **app.py가 import 하므로 반드시 같이 올리기** |
| `verify_engine.py` | 검증 스크립트 (37개 시험) |
| `data/` (선택) | 경량 항해 데이터. 있으면 647MB를 다시 받지 않음 |

## 1. 계산식이 바뀐 점
- 실시간 화면의 한 스텝 계산 = `verified_sim.step` 그대로 (식별 출처는 `verified_sim.py` 머리말, 원문 캡처는 `수식_출처_원문캡처.pdf`)
- 자동 튜닝의 일괄 계산도 같은 식으로 고침 → 실시간과 10⁻¹³까지 같음 (V13)
- 고친 것
  1. 기록 시점: 상판각[k] = 선박각[k] + 관절각[k] (이전: 관절각[k+1]을 짝지어 잔차가 작게 나왔음)
  2. 1차 서보: 정확 이산화 a = e^(−dt/τ) (이전: 오일러 근사, 시정수가 약 10% 틀림)
  3. 센서→구동 지연 슬라이더 추가 (0~100 ms, 다음 학기 실측값을 넣기)
- 사이드바 "서보 모델 → 기존 앱 결과 재현"을 고르면 이전 숫자(0.497, 0.383)를 그대로 다시 얻을 수 있음 (V11)

## 2. 화면
- 3D 화면(왼쪽)과 Roll·Pitch 그래프(오른쪽)를 한 화면에 배치 → 스크롤 없이 같이 보임
- 사이드바 "3D·그래프 화면 높이"로 노트북/큰 모니터에 맞게 조절 (400 / 470 / 560 px)
- 그래프는 최근 30초만 고정 폭으로 흘러감
- 맨 위 지표에 "RMS비(최근 30초)" 추가
- 선박 제원·데이터 출처는 접어 둠 (펼치면 보임)
- "📐 계산식 출처와 자체 검증" 패널: 출처 표 + 버튼 한 번으로 현재 설정 검증

## 2-1. 가상 파도 WMO 0~9 단계와 보정 한계 (v3.1)
- 사이드바 "WMO 해상상태 단계"에서 0~9를 고름. 각 단계 Hs 구간의 가운데 값을 쓰고, 주기는 Pierson–Moskowitz 완전발달 해역 관계
  Tp = (2π/0.877)·√(Hs/(0.21·g)) ≈ 4.99·√Hs (Stewart, Introduction to Physical Oceanography 16.4절의 ω_p = 0.877g/U, H1/3 = 0.21U²/g 에서 U 소거)
- "선박 흔들림 크기 모델": 이전 앱의 가정 배율, 또는 Akademik 실측 창에서 맞춘 회귀식 (선박 기울기 RMS = c·Hs^p).
  Akademik 133.5 m ≈ 한나라호 133 m 라서 최소 선박 기준으로 쓸 수 있음. 실측 Hs 범위 밖은 외삽.
- "🌊 WMO 단계별 보정 한계" 패널
  - 판정 기준(상판 기울기 RMS·최대각·서보 포화율·리밋사이클)을 정하고, Hs만 / Tp만 하나씩 바꿔 평가
  - ① 가상 기준: WMO 0~9 또는 Hs 촘촘히 → "WMO ○까지 기준 만족"
  - ② 실측 기준: Akademik 실측 창을 WMO 라벨별로 평가 (데이터에 있는 단계만 판정 가능)

## 3. 데이터 다시 안 받게 하기
- **로컬 실행**: 한 번 받은 뒤에는 체크섬(647MB)도 다시 계산하지 않음 (`.md5ok` 스탬프)
- **Streamlit Cloud 등 코드 올릴 때마다 서버가 새로 생기는 곳** (한 번만 하면 됨)
  1. 실제 항해 모드에서 마지막 다운로드를 한 번 함
  2. "🔁 코드를 고칠 때마다 다시 받지 않게 하기" → **경량 데이터 파일 만들기** → **data 폴더 내려받기(zip)**
  3. 압축을 풀어 나온 `data/` 폴더를 GitHub 저장소 맨 위(app.py 옆)에 올림
     (부분 파일 하나가 약 10~15MB라 GitHub 웹 업로드로도 가능)
  4. 그다음부터는 앱이 `data/`를 바로 읽음 → 다운로드 없음
- 경량 파일에는 계산에 쓰는 롤·피치·시각만 담음 (시각 0.01초 단위, 각도 float32). 선수방향·속도는 화면 표시용이라 뺌

## 4. 검증 실행

```
python verify_engine.py                         # 엔진 시험
python verify_engine.py 이전앱.py app.py         # + 이전 결과 재현(V11), 튜닝=실시간(V13)
```
